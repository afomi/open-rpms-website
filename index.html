Open source · Community maintained

Open-source business processes for healthcare.

The Resource and Patient Management System (RPMS) encodes 40+ years of clinical and administrative workflow knowledge for the Indian Health Service. This site distills those patterns — the domain model, workflows, architecture, and security model — into open, reusable knowledge for anyone building health systems.

Not a transcription of MUMPS globals. An opinionated extraction of the ideas worth carrying forward.

Why this exists

RPMS serves one of the most underserved patient populations in the United States. It has done so reliably for decades, in low-bandwidth, resource-constrained environments, at facilities ranging from a two-room rural clinic to a 200-bed area hospital.

The implementation — MUMPS globals, VAX-era conventions, terminal-based interfaces — is not what's valuable. The operational knowledge embedded in the design is.

This site is an attempt to extract that knowledge: the domain model, the workflow patterns, the security architecture, the hard-won decisions about what healthcare IT actually needs to do under pressure. The goal is to make those patterns available to anyone building health systems — free of the MUMPS runtime, the IRIS license, and the 1990s UX.

In 2020, OSEHRA — the institutional home for open-source VistA and RPMS — closed its doors. The software kept running. The community infrastructure did not survive. This project is part of an effort to rebuild that infrastructure from the ground up, maintained by the people who use and deploy the system.

One piece of that work is a release people can run. IHS's own way of assembling one was not in the public files, so we built a way. It keeps the certified patch levels current, and the same release runs on the database IHS uses and on YottaDB. How a release is built says what is in it, and what is not.

Contributors

OpenRPMS is maintained by a loose federation of organizations working on open-source RPMS infrastructure. Each contributes a different piece. All of it is open.

CivicActions

Maintains docker-vista, a container pipeline that turns the public RPMS source into a runnable IRIS image.

Lakeraven

Maintains the current release: the public files reassembled, kept up to the certified patch level, and ported to YottaDB so it runs without an InterSystems license. How a release is built is the plain-language account. The working record is rpms-ops.

Civic Studio

Maintains this site. Documents the domain model, integration layer, and security findings. Extracted BMW from binary to portable XML.

WorldVistA

The 501(c)(3) nonprofit that inherited OSEHRA's VistA repositories. Hosts FOIA-RPMS releases and maintains institutional continuity for the open-source VistA community.
